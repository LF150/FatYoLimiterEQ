# Deployment

1. Deploy this directory to a cloud service that runs Node 22 or Docker and provides HTTPS.
2. Put the exact authoritative HTML plugin in `public/plugins/` through the controlled deployment process.
3. Open the service URL on the iPhone.
4. Use Diagnostics for device/audio capability information and the parallel worker benchmark.

The server does not emulate an iPhone. Web Audio/JavaScript execute on the iPhone, which is intentional.

Browser JS cannot provide authoritative physical iOS process CPU/RAM figures. A later native host can add those if needed.

Do not add a public upload endpoint for proprietary plugins. Keep credentials, certificates and signing keys outside the project.
